# Pit Crew

> 사고 직후 정차부터 마무리까지 안내하는 Pleos Connect 차량용 앱

사고가 나면 정차 확인 → 안전 확보 → 부상 확인 → 현장 기록 → 상대방 확인 → 차량 상태 기록 → 마무리까지 7단계로 짧게 안내합니다. 모든 안내는 **참고용**이며 법적 판단·과실 판단·의료 조언을 하지 않습니다.

## 1. 실행 방법

**APK로 설치:** **(최종 제출 시 채움)**

**소스에서 실행:**
1. Android Studio에서 이 폴더(`pit-crew`)를 엽니다.
2. Gradle JDK를 **JDK 21**로 설정합니다. (Settings > Build > Gradle > Gradle JDK)
3. Gradle Sync 후 Pleos Connect Emulator를 켜고 ▶ Run 합니다.
4. 홈에서 [사고가 났어요]를 누릅니다. 처음에는 사용할 기능(위치·음성·네트워크)을 고르는 화면(SC-205)이 먼저 나옵니다.

실차 시연은 지원되지 않아 에뮬레이터 기준으로 개발·검증했습니다.

## 3. 테스트 환경과 설정

| 항목 | 값 |
|---|---|
| 에뮬레이터 | Pleos Connect Emulator v2.1.0, Pleos 시스템 이미지 API 34 (일반 Android Automotive 이미지는 사용하지 않음) |
| 빌드 | Android Studio, Gradle 8.10.2, JDK 21, Kotlin 2.0.0, Jetpack Compose. minSdk 28 / compileSdk 35 |
| SDK | Vehicle 2.3.2 (Vehicle Service 2.3.22), FusedLocation 1.1.3, NaviHelper 3.0.5, TextToSpeech 3.3.1, SpeechToText 3.3.1 |
| 화면 | 1682×1210dp (밀도 160) |

시연 전에 켜 둘 설정:
- 위치: 사고 모드 첫 진입(SC-205)이나 설정·정보(SC-500)에서 위치를 켜고, 시스템 권한 창에서 [허용]을 누릅니다.
- 주소·날씨: 위치와 네트워크를 모두 켜고 인터넷에 연결합니다(안 되면 "확인 불가"로 표시되고 사고 모드는 계속됩니다).
- 길안내(SC-280): 에뮬레이터의 내비 앱 화면을 먼저 한 번 열어 둡니다.
- 문·창문 값은 Virtual Console(`adb forward tcp:8088 tcp:8088` 후 `http://127.0.0.1:8088/`)에서 바꿔 SC-250에서 확인합니다.
- 시연을 반복하려면 `adb shell pm clear --user 10 ai.pleos.playground.sample.vehicle`로 설정과 저장 기록을 지웁니다.

## 4. 안내와 한계

**가상 값과 시연용 안내**
- 에뮬레이터의 차량 값은 **가상 값**이며 화면에 "가상 차량 값" 배지를 표시합니다. 읽지 못한 값은 "확인 불가"로 표시하고 앱은 종료되지 않습니다.
- 정차 여부는 속도·기어를 읽지 않고 **사용자 확인(SC-200)** 으로 판단합니다.
- 보험사 전달(SC-290)은 **시연용 가상 보험사(목업)** 입니다. 실제 보험사로 전달되지 않고 네트워크도 쓰지 않습니다.
- 길안내(SC-280)의 후보는 **시연용 예시 장소**입니다. 실제 병원·정비소가 아니고 추천이 아닙니다.

**지원하지 않는 항목**
- 차량 제어(set 호출, `CONTROL_*` 권한 없음, 차량 권한은 읽기용 5개만 선언), 사고 자동 감지, 에어백, 문 잠김, 차대번호, 비상등 자동 확인, 타이어 값
- 법적 판단·과실 판단·의료 조언, 상대방 정보·사진·차대번호의 저장·전송, 차량 화면에서의 타이핑
- 실제 보험사 연동
- 사고 기록 내보내기(PDF)와 기록 무결성(변조 확인): 이번 버전(1차 제출)에서는 지원하지 않으며, 서류 통과 후 고도화할 예정이지만 아직 구현되어 있지 않습니다.

**확인하지 못한 것과 알려진 한계**
- 실제 차량에서는 확인하지 못했습니다. 공식 샘플의 차량 권한 15개를 지웠고, 그중 9개는 에뮬레이터에 정의가 없어 실제 차량 영향을 확인하지 못했습니다.
- 음성 안내(TTS): 헤드폰으로 소리가 나는 것은 확인했습니다. 한국어 발음의 자연스러움은 확인하지 못했습니다.
- 길안내는 목적지를 내비 앱에 전달할 뿐이며, 에뮬레이터에서는 내비 앱 화면이 열려 있어야 시작됩니다. 경로 계산 범위는 확인하지 못했습니다.
- 긴급 안내(SC-221) 문구는 초안이며 공식 안내와의 대조를 마치지 못했습니다. 주행 중 플랫폼이 사용을 제한하는지도 확인하지 못했습니다.
- 사고 기록은 이 기기에 최근 1건만 저장합니다. 앱이 외부 서버로 보내는 것은 주소·날씨 조회용 좌표(반올림)뿐입니다.
- 음성 메모는 인식이 동작하지만 정확도는 환경에 따라 다를 수 있습니다(말한 내용과 다른 글자가 나올 때가 있음).
