# Pit Crew 진행 기록 (PROGRESS)

작업이 끝날 때마다 이 문서를 갱신한다. 다음 날 어디서부터 시작할지 이 문서만 보면 알 수 있어야 한다.
기준 문서: `docs/PLAN.md`(순서), `docs/SPEC.md`(화면 명세), `docs/design/`(디자인), `CLAUDE.md`(규칙)

## 갱신 규칙 (Claude Code)

- 작업 하나(또는 Phase 하나)를 마칠 때마다 **맨 위 "현재 상태"와 아래 "작업 기록"에 항목을 추가**한다.
- 기록은 짧게 쓴다. 한 항목은 5줄 안쪽: 한 일, 확인한 것, 확인하지 못한 것, 다음 할 일.
- **실제로 빌드하고 에뮬레이터에서 확인한 것만 "완료"로 쓴다.** 확인하지 못한 것은 "미확인"으로 구분해 적는다.
- SDK 호출이 에뮬레이터에서 되는지/안 되는지는 결과를 그대로 기록한다(5절). 안 되면 "확인 불가 처리"를 함께 적는다.
- 키, 토큰, 비밀번호, 개인 이메일, 실제 이름·전화번호를 적지 않는다.
- 사용자가 결정해야 하는 일은 "결정 필요" 절에 올리고, 결정되면 "결정 기록"으로 옮긴다.
- 커밋을 만들었다면 커밋 메시지(화면 ID 포함)를 항목에 적는다.

## 3. 환경 메모

| 항목 | 값 |
|---|---|
| 프로젝트 위치 | Android Studio 프로젝트 루트 폴더(`pit-crew`) |
| Gradle / JDK | Gradle 8.10.2, Android Studio의 Gradle JDK는 jbr-21 (JDK 25로는 빌드 실패) |
| 빌드 확인 | Android Studio > Build > Compile All Sources (Make Project 메뉴 없음) |
| 에뮬레이터 | Pleos Connect Emulator v2.1.0, Pleos 시스템 이미지 API 34 |
| 앱 영역 | 1682×1210dp, 밀도 160 (Logcat `WINSIZE` 측정값) |
| 권한 | 읽기 권한 20개(CAR_* 16, READ_* 4), CONTROL_* 없음 |
| SDK | Vehicle SDK 2.3.2, Vehicle Service 2.3.22. 추가 예정: FusedLocation 1.1.2, NaviHelper 3.0.5, TextToSpeech 3.3.1, SpeechToText 3.3.1 |

## 4. 알려진 상태와 주의

- 임시 측정 코드(`TEMP-WINSIZE`, MainActivity.kt의 Logcat 출력)가 아직 남아 있을 수 있다. **Phase 0에서 제거 여부를 확인한다. (미확인)**
- 샘플 앱의 제어(set) 호출, "Apply change", 리플렉션 탐색 코드가 남아 있다. Pit Crew 화면에서는 쓰지 않는다. Phase 0에서 분리한다.
- 에뮬레이터의 차량 값은 가상 값이다.
